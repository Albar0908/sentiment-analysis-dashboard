# 🎬 IMDb Sentiment Analysis Dashboard

Dashboard web interaktif untuk klasifikasi sentimen ulasan film menggunakan arsitektur **TF-IDF Vectorizer + Multi-Layer Perceptron (MLP Classifier)** dan di-deploy menggunakan **Streamlit Community Cloud**.

## 🚀 Fitur Utama
- **Executive Metric Cards**: Ringkasan volume data, rasio positif vs negatif, dan rata-rata confidence score.
- **Visualisasi Interaktif**: Plotly Donut Chart dan WordCloud ulasan film.
- **Batch CSV Analysis**: Upload file CSV dan lakukan prediksi otomatis dengan progress score.
- **Real-time Prediction Sandbox**: Uji coba ulasan film mandiri dengan gauge meter interaktif.
